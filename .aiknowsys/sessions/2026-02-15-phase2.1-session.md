## Implementation Strategy

### 1. Markdown Generator (lib/events/markdown-generator.ts)

```typescript
export class MarkdownGenerator {
  /**
   * Generate markdown from events
   * Matches existing session template format
   */
  generateSessionMarkdown(events: KnowledgeEvent[]): string {
    const sections = {
      goal: this.extractGoal(events),
      changes: this.extractChanges(events),
      validation: this.extractValidation(events),
      learning: this.extractLearning(events)
    };
    
    return this.renderTemplate(sections);
  }
}
```

### 2. Hybrid Storage Methods

**Modify SqliteStorage:**
```typescript
async createSession(metadata: SessionMetadata): Promise<void> {
  // 1. Store initial events
  const events = [
    { type: 'session_started', data: { title: metadata.title } },
    { type: 'goal_defined', data: { goal: metadata.goal } }
  ];
  
  await Promise.all(
    events.map(e => this.insertEvent({ ...e, sessionId: metadata.id }))
  );
  
  // 2. Generate markdown from events
  const markdown = this.mdGenerator.generateSessionMarkdown(events);
  
  // 3. Store in sessions table (existing workflow)
  await this.db.run(
    'INSERT INTO sessions (session_id, content, ...) VALUES (?, ?, ...)',
    [metadata.id, markdown, ...]
  );
}
```

### 3. Migration Tool (lib/migration/event-migrator.ts)

```typescript
export class EventMigrator {
  /**
   * Convert markdown session → events
   */
  async migrateSession(sessionId: string): Promise<MigrationResult> {
    // 1. Read markdown from sessions.content
    const markdown = await this.storage.getSessionContent(sessionId);
    
    // 2. Parse markdown → events
    const parser = new MarkdownEventParser();
    const events = parser.parse(markdown);
    
    // 3. Store events
    await Promise.all(
      events.map(e => this.storage.insertEvent({ ...e, sessionId }))
    );
    
    // 4. DON'T delete markdown (keep for backward compat)
    return { eventsCreated: events.length, originalPreserved: true };
  }
}
```

## 🔧 Database Corruption Fix (21:30) ✅
**Status:** RESOLVED (16:00)  
**Issue:** `SQLITE_CORRUPT_VTAB` errors in 7/8 hybrid storage tests

**Root Cause:**
FTS5 external content tables (`content=sessions, content_rowid=rowid`) combined with manual triggers create incompatible state.

**Solution:**
1. ✅ Fixed [schema.sql](lib/context/schema.sql#L122-L179) - Self-managed FTS tables
   - Removed `content=`, `content_rowid=` options
   - Changed UPDATE triggers from DELETE+INSERT to UPDATE
   - Use column names (id, plan_id) instead of rowid
2. ✅ Added graceful fallback in [sqlite-storage.ts](lib/context/sqlite-storage.ts#L1426-L1453)
   - Try-catch around `queryEvents()` in `getSessionContent()`
   - Falls back to markdown if events corrupted
   - Logs warning for debugging
3. ✅ Fixed test expectations - Added validation events, removed invalid assertions
