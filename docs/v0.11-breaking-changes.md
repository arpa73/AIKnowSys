# v0.11.0 Breaking Changes

## Summary

v0.11.0 shifts onboarding to an AI-native conversational workflow.

## Removed CLI Onboarding Commands

The following commands are removed:

- `aiknowsys init`
- `aiknowsys scan`
- `aiknowsys migrate`

Use conversational onboarding via `.github/onboarding-setup.md` instead.

## Removed Deliverables

Stack templates were removed:

- `templates/stacks/**`

The project now relies on AI guidance + Context7 docs instead of prescriptive stack template files.

## Plan Pointer Artifacts Removed

The old pointer workflow artifacts are removed:

- `.aiknowsys/CURRENT_PLAN.md`
- `.aiknowsys/plans/active-*.md`

Use `status` in `PLAN_*.md` and query active work via:

- `mcp_aiknowsys_get_active_plans()`
- `npx aiknowsys query-plans --status ACTIVE`

## Migration Guidance

For new setups:

1. Install AIKnowSys
2. Ask your AI assistant to initialize using `.github/onboarding-setup.md`
3. Continue with MCP-first workflows from `AGENTS.md`

For existing users, maintenance commands continue to work (`update`, `check`, `audit`, query/export commands).
